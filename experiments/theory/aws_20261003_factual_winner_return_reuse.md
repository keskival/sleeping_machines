# Factual winner return reuse: retain every alternative, avoid duplicate work

For a fixed detached entering state, factual first time, legal real-state
writes and common future randomness, forcing the factual winner reproduces
the factual suffix. Therefore its detached all-target return is already
available from the factual losses. All categorical alternatives still appear
in sum_i pi_i stopgrad(Q_i): execute shadow forwards only for LOSING candidates
and fill Q_winner with the factual return. Detachment is essential: otherwise
this accidentally adds winner payload/clock loss derivatives a second time.

With U candidates and R races, shadow lanes fall from U*R to (U-1)*R. For
pool2 this halves shadow lanes/events EXACTLY. It does not halve total training
work automatically: factual/backward/normalization/optimizer remain and
winner recording/return assembly also costs work. Measure full traced totals
and wall separately. No inference/architecture change: private deep persistent
state, time computations, scores/keys/values, sparse realwrites all retained.
No variance increase from sampling: EVERY candidate return remains present.

Independent double-precision private/shared nonempty-state T1/T3 contracts
compare EVERY parameter gradient against frozen all-lane full replay,
bitwise factual logits/private-state/RNG and exact lane/event counts, with
forward/backward operator audits. Then actual sibling full-driver interrupted/
resumed optimizer/cursor/RNG/work contracts in both replayfamilies and p16
learning/RSS smokes before10M fits. Leading original results are preserved.

The full factual pass uses one lane; the old forced-winner replay uses many
lanes. Floating arithmetic can differ slightly with shape, so gradient
comparison must state tolerance; this is exact conditional algebra, not a
promise of bitwise equality with the old optimizer trajectory. Recovery of
the new implementation itself must remain bitwise exact. Labels affect only
loss/credit, never the pre-update factual states and chronology. Fixed first
arrival times cannot be replaced with losing routes' individual arrivals.

New10M replay variants use the same initialization/data/pass/update/DEV bounds
as the full driver, unique tags, all work charged. Teacher checkpoints remain
unchanged. Small fits validate learning/resources only, never languagequality
advantage. Full corrected all-alternative replay is retained; no candidate

calculation. Potential downstream use: analogous gesture optimization after
