## Failure addressed and retained architecture

The frozen prefix probes established retention but not learned joint prediction.
The new episode is [24,b1,1-b1,25,b2,1-b2,noise...,26], with target b1 XOR b2.
Noise uses symbols 2..23 and has length at least eight. Every identical noise
suffix appears with all four bit pairs, equally weighted. Complements make
all observed unigram totals identical too: the old parity probe's raw bit
totals were not balanced. Earlier labels are never inputs to another episode.

For orders 1..8, query contexts end in the unique cue 26, which never occurred
earlier in the episode. Fit-prefilled query-context counts are shared; causal
prefix updates cannot change these addresses. The root symbol totals are
identical. Therefore query suffix/count inputs for orders 0..8, including
unigram evidence, are identical within each quartet, while labels are balanced.
Any predictor restricted to those inputs has at least one bit expected query
logloss. The complete prefix determines the target. Count-table inspection at
arbitrary other addresses or recurrent counting of the entire prefix is outside
this restriction; this is not an all-counting impossibility theorem.

Train the unchanged native temporal core and its already contracted learned
delay-tap extension. Races, addressed persistent receiver state, separate
keys/values, computational delays, cross-head content mixing and counterfactual
credit remain. No explicit bit extraction, XOR feature, parity lookup or oracle
delivery enters these models. Query classification uses the existing head's
two bit-symbol logits. This grants every model the binary answer alphabet.

The tap extension is a labelled information-path intervention: per-layer
bounded delayed-input memory and trainable fractional event delays, zero tap
maps initially nest native exactly. It retains native recurrence, introduces
additional projections/storage and shortens possible lag paths. It does not
implement content-based KV race retrieval or remove nonlinear producer-credit
limits. Compare native full, tapped full and same-width tapped shallow, not
only a width-changing minimal control. Changing depth changes initialization;
the paired architecture comparison is not an exact isolated depth derivative.

## Bounded exploratory protocol and admission

Initial pilot: gap 8; eight fitting suffix groups (32 labelled episodes),
16 development groups (64 episodes), 16 passes, payload 8, four layers for
full and one for shallow, two heads/two receiver candidates. Adam .003,
eight query targets per optimizer update. Each episode starts from an empty
core; credit spans the complete 15-input episode. Full and tapped full share
zero-nested initialization. Race noise is coupled across the four bit pairs
and model variants by episode-group/pass seeds; evaluation never advances
fitting RNG. Target-only loss is identical for all arms. This is not ordinary
whole-stream language supervision.

All prefix inference and backward work, every candidate/losing-value proposal,
gradient normalization/clipping, Adam and evaluation are charged. Numerical
prerequisites must verify causality, train/inference forward identity, tap
nesting, real target normalization, next-update and interrupted-driver
recovery, query-count equality and complete sampled FLOP coverage. Save model,
optimizer, cursor and RNG at every optimizer boundary. Whole-fit resource
estimates use explicitly recorded full optimizer windows; actual input/event
and activity counts and total wall/RSS are separate. No energy claim follows.
Each prerequisite or fit uses a new one-job queue through run_safe, one CPU
thread, bounded RSS/VMS and at least 8 GiB available memory. No dense control
training is moved from AWS to this host.

An exploratory useful-dependency gate requires held-out query accuracy at
least 75% and loss at most .8 bits; balanced count controls have a one-bit
lower bound. To attribute an additional benefit to taps/depth, demand .05
bits over the respective native/shallow control and report extra work.
Fixed 16-pass development selection is exploratory, not confirmation.
No larger fit is automatically justified by a best seed. A promising arm
needs fixed selection and new suffix groups across independent fitted seeds.
A failed fit remains evidence about this restricted architecture/objective,
with separate single-bit retention and joint-decoding diagnostics before any
claim about a general impossibility. No automatic broad superiority claim.
