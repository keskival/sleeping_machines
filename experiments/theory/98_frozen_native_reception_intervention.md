# A bounded actual-native test before learning a reception window

Theory97's complete arrival/credit contracts pass, including a constructed
gradient sign reversal. They do not demonstrate a useful native window. The
next step changes one real reception site in frozen saved models and tests
extra information versus amplitude, waiting and persistent-write effects.
This avoids guessing another optimizer or launching a full architectural fit.

Use the two existing native256-fit/four-pass seed6/7 producers at their fixed
final online states, plus their exact initial reservoirs. Retain all native
weights, physical state evolution/transport, independent head races, causal
source readiness, addressed memory and separate keys/values. At observed packet
event19, layer0/head0 only, sample the original independent candidate clocks
with exactly the original RNG consumption. Close a fixed window H after its
first physical arrival. Evaluate heard value proposals only; transport each
to the actual deadline. Commit each heard receiver's actual memory proposal
at the original native admission timestamp. Deeper processing and the following
query consume the changed state. This is a fixed-first deadline, not popcorn.

One site rather than every event is a deliberate diagnostic restriction:
the extra write has a subsequent event and deeper computation in which to
matter, and the work increase is bounded. The packet cadence itself remains
fixed; variable internal races cannot establish natural-silence learning.
Query observation cutoff remains1s. Final physical ready time is measured,
because extra processing latency cannot be treated as free observation time.

Enumerate zero-width original and H=.001/.003 seconds under five modes:

- window_sum: heard transported values sum; every heard memory is committed.
- winner_gain: same clock-derived heard count and deadline, only the winner
  delivered/committed, multiplied by that count (amplitude control).
- window_mean: heard sum divided by count, with all heard commits.
- winner_wait: same deadline, winner only, no count amplification.
- delivery_only_sum: heard sum, but only the winner memory is committed.

These controls hold the sampled discovery/deadline fixed at the intervention
site; changed contents/writes may change later races legitimately. A frozen
window gain by itself does not distinguish extra message information from
confidence effects. The delivery-only control is a diagnostic omission,
never promoted to the integrated architecture.

not development or official-test selection. No decoder/encoder fitting,
