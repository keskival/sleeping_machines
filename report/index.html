Sleeping Machines · experiment log · 23 September 2026

Computing with races, cancellations and near misses

Sleeping Machines proposes that computation can happen in time rather than memory: candidate events race, the first to fire cancels the rest, and the cancelled ones keep a trace of how close they came for a teaching signal to use later. This log reports what the first preregistered experiments show, including the parts that did not work.

One race, one winner, two counterfactual traces
Three output nodes integrate the same input spikes. B reaches threshold first and fires; its inhibition cancels A and C, whose distance to threshold Δ is frozen. When the teaching event arrives and names C, only the cancelled node's frozen record makes it possible to credit C.

The ingredients, as the experiments implement them:

  • Time instead of addressing. A value is when something happens. Nothing is looked up; events are scheduled.
  • The future is part of the state. Pending events live in a pool and can be cancelled before they fire. The simulator has no global clock; it jumps from event to event and counts every operation.
  • Decisions are races. Accumulators integrate evidence; the first to reach threshold decides and inhibits the rest.
  • Losers leave traces. A cancelled node keeps Δ, its distance to threshold at the moment of cancellation. A later teaching event can credit near misses, not just the node that fired.

E4 · single racing layer · 10 held-out seeds · 6,000 teaching events

A cancelled node can be taught

K output nodes race over sparse spike patterns; a teaching event arrives after the race. Rules that only credit nodes that fired (the STDP / reward-modulated family) can only punish a wrong winner. The counterfactual rules can also promote the target, which usually never fired. cf_margin additionally depresses only competitors that came close.

E2 · Poisson evidence race · 4 classes · 5 seeds × 2,000 trials

Races decide as fast as the evidence allows

Evidence arrives as Poisson spikes whose coherence (how strongly they favour the right answer) varies unpredictably between trials. The race stops at its first fire event and cancels all pending input events. It is compared with a clocked decoder that counts for a fixed time, and with the multi-hypothesis sequential probability ratio test (MSPRT), which knows the exact likelihoods.

E6 · hidden layers · latency-coded MNIST

Hidden layers: credit flows, but depth does not pay yet

Counterfactual race learning (CRL) sends the output error back as events to a hidden layer of competing groups. Hidden nodes that fired, and hidden nodes that were cancelled close to threshold, are updated from their locally stored traces. For these non-leaky single-spike neurons the exact gradient is zero almost everywhere, so the frozen Δ plays the role a surrogate gradient plays in conventional spiking-network training. A batched closed-form solver agrees with the discrete-event engine on 100% of decisions.

E5 · capacity scaling · same sparse connectivity for every model · 3 seeds

Work tracks activity, but most of that is sparsity

The number of classes K grows from 256 to 16,384 while each input still activates about 21 channels. Every model gets the same fan-in of 64 synapses per node, starts from random connectivity, and grows synapses by the same local rule: a taught node connects to the active inputs it lacks. A sparse softmax that only touches synapses of active inputs is the fair baseline, because most of what "event computing" saves comes from sparsity itself. The race's own contributions are early termination and learning that touches only near misses. The race's threshold rises with every input spike: global inhibition as one shared counter, so the race runs on relative evidence.

Energy: modest gains at matched accuracy, so far

The simulators count every synaptic event, spike, plasticity update and multiply-accumulate. Those counts are priced on hardware profiles built from published figures: 45 nm digital logic and SRAM (Horowitz, ISSCC 2014) and measured Loihi energies (Davies et al., IEEE Micro 2018). The "suitable architecture" is an idealized event-driven, near-memory design: because spikes are binary, a synaptic event is an 8-bit weight fetch plus an addition, with no multiply and no clock. These are order-of-magnitude estimates, not measurements of a chip.

What comes next

  • Make depth pay (E6). Diagnose why a single racing layer still matches the hidden-layer network: latency-coded MNIST lets races decide on the first instant of saturated pixels, which caps the evidence any layer sees. Next steps are several spikes per hidden node, a decision threshold that learns, and learned delays (the timing counterfactual in the design).
  • Dormant capacity (E5). The orders-of-magnitude energy argument only applies when most of a large network stays silent for any given input. That scaling has to be measured, not assumed, against sparse (mixture-of-experts style) dense baselines.
  • A benchmark where timing matters. Spiking Heidelberg Digits (spoken digits as cochlear spikes), where learned delays are state of the art. It needs the GPU, which the current container cannot see.
